# Climate-Induced Species Shift and Catch Dependence in Recreational Fisheries

This is the code and data repository for the manuscript **"Climate-Induced Species Shift and Catch Dependence in Recreational Fisheries"** by Andrew Carr-Harris, Jorge Holzer, and Geret DePiper, submitted to *Nature Communications*.

## Overview

This repository contains the scripts and permitted initialization data used for the manuscript analyses and figures. The workflow uses **Stata**, **R**, and **MATLAB**. Run each script in the software indicated below and follow the input/output dependencies.

Only data needed to initialize the public analysis are distributed. Intermediate datasets are generated by the scripts and are not included in the repository. Restricted confidential data are not distributed. Where an approved derived initialization input replaces a restricted-data preparation stage, that boundary is identified in the workflow documentation.

Some survey datasets requiring NOAA-NMFS disclosure review are available upon request from Sabrina Lovell ([sabrina.lovell\@noaa.gov](mailto:sabrina.lovell@noaa.gov){.email})

There are many code files and input data sources in this repository. While AI (GPT-5.6 Sol and Claude Opus 5) was used to optimize code in this repository and to assist with producing this README, bugs may still exist. If you encounter any issues with or have any questions about the code or data, please email Andrew Carr-Harris ([acarrharris\@gmail.com](mailto:acarrharris@gmail.com){.email})

## Directory setup

Before running the analysis, set the repository root in each script's directory configuration:

-   **Stata:** edit `dir_root` in the entry points and standalone scripts in folders 01 and 04–08. Folder 01 child scripts inherit settings from `run_step_01.do`.
-   **R:** edit `project_dir` in each temperature script.
-   **MATLAB:** edit the `cd` command in each copula script to point to the repository's `data/` directory.
-   **R simulation and results:** align `input_data_cd`, `input_code_cd`, and `figure_dir` wherever declared in folder 09. Child scripts contain their own directory settings; editing only the wrapper does not update them.

The example paths in the scripts refer to the authors' computer and must be replaced with the local checkout location. The same repository root must be used across all software.

|------------------------------------|------------------------------------|

| `data/` | Distributed initialization inputs and locally generated intermediate datasets |
| `mrip_data/` | Public MRIP trip and catch files downloaded separately by the user |

Ensure these directories exist and are writable. Unless otherwise stated, all dataset inputs and outputs listed below are located in `data/`. Generated files may be written there during a run, but are not distributed as repository inputs.

The wrapper searches years **1982–2024**, waves **1–6**. It skips missing files and does not download them; a successful run is not a check that the intended historical inventory is complete.

Confidential VTR locations used to construct the fishing footprint are excluded. The public spatial workflow reads the supplied `data/VTR_convex_hull.gpkg`, layer `VTR_convex_hull`, and does not reconstruct that footprint from confidential points. ## Workflow and execution order

1.  Compile historical catch-per-trip, directed fishing trips, and regulations (**Stata**).
2.  Extract historical temperatures and projected temperature deltas (**R**).
3.  Construct climatology and bias-correct projected temperatures (**R**).
4.  Generate temperature draws and estimate catch-per-trip regressions (**Stata**).
5.  Estimate copulas and generate residual draws (**MATLAB**).
6.  Project catch-per-trip and prepare fishery simulation catch inputs (**Stata**).
7.  Prepare angler preference inputs (**Stata**).
8.  Prepare age and trip-cost inputs (**Stata**).
9.  Calibrate and run the fishery simulation, format outputs, and generate manuscript figures and values (**R**).

Folders 01 and 02 can be prepared independently. Within folder 02, run both historical extractions before the compiler; projected-delta extraction can run independently. Folder 03 requires the newer historical extraction and projected deltas. The two folder 04 scripts are independent once their respective inputs exist. All four folder 05 scripts can run in any order after catch regressions. Folder 05 generates residual draws; catch-per-trip projection follows in folder 06.

## Software and filename conventions

Braces denote filename alternatives, not literal characters. Area `1` is inshore and area `2` is offshore; mode `2` is for-hire and mode `3` is private boat.

### 5. `05_copula_projection`

Run the four MATLAB scripts after the corresponding residual CSVs have been generated in folder 04:

| MATLAB script | Input CSV | Output TAG |
|------------------------|------------------------|------------------------|
| `copula_fit_area1_newmode2.m` | `logresiduals_Sept_28_2026_area1newmode2.csv` | `area1_newmode2` |
| `copula_fit_area1_newmode3.m` | `logresiduals_Sept_28_2026_area1newmode3.csv` | `area1_newmode3` |
| `copula_fit_area2_newmode2.m` | `logresiduals_Sept_28_2026_area2newmode2.csv` | `area2_newmode2` |
| `copula_fit_area2_newmode3.m` | `logresiduals_Sept_28_2026_area2newmode3.csv` | `area2_newmode3` |

These scripts estimate five copulas and generate residual draws for subsequent catch-per-trip projection. They do not themselves generate the projected catch-per-trip datasets. They can run in any order, with their working directory set to `data/` and the Plackett helpers available on the MATLAB path.

Each script writes:

| Generated output | Contents and use |
|------------------------------------|------------------------------------|
| `copula_estimates_{TAG}.csv` | Copula parameter estimates, bootstrap confidence intervals, bootstrap counts, and weighted association summary |
| `residual_draws_{family}_{TAG}.csv` | Paired both-species log residuals; columns `draw_id`, `r_cod`, `r_had` |
| `residual_draws_onespecies_{TAG}.csv` | Single-species residual pools; columns `draw_id`, `r_cod_only`, `r_had_only` |
| `residual_draws_uncond_{TAG}.csv` | Independently sampled unconditional residual pools; columns `draw_id`, `r_cod_all`, `r_had_all` |

`family` is `Clayton`, `Frank`, `Gumbel`, `Gaussian`, or `Plackett`. Each residual CSV contains 2,000,000 draws under the supplied settings; each copula script uses 5,000 bootstrap replicates. There are eight generated CSVs per TAG, or 32 across all four strata.

Residual outputs feed the catch-per-trip projection scripts listed in folder 06. The independent treatment uses the unconditional residual file; no `residual_draws_independent_{TAG}.csv` is needed. All these outputs are regenerated and are excluded from the distributed data inventory.

| Order | Script | Role and generated handoff |
|------------------------|------------------------|------------------------|
| 1 | Wrapper Part A → `find_p_star_values_corr.R` → `calibration_loop_corr.R` | Calibrate harvest against baseline targets; cache sampled costs/preferences and baseline outcomes; write per-draw p-star checkpoints and combined p-star table |
| 2 | Wrapper Part B → `projection_corr.R` | Use calibrated p-stars, baseline caches, and projected catch inputs; write correlated model and Kendall's tau results |

| 4 | Wrapper Part C → `projection_close_fishery.R` | Set both bag limits to zero for baseline closure runs; combine results across draws within each year |
| 5 | Wrapper Part D → `format_model_output.R` | Combine projection workbooks, integrate closure values and monthly discard mortality, and create coast/state/mode results |
